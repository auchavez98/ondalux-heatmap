# HeatCraft (provisional name)

Open source WiFi design and survey tool with heat maps, written in Rust.

**Status: early development (Phase 1, in progress).** Nothing is usable yet.

| Component | State |
|---|---|
| `heatcraft-core` (RF engine) | skeleton |
| `heatcraft-io` (projects, import/export) | skeleton |
| `heatcraft-scan` (WiFi scanning) | STUB, Phase 2 |
| `heatcraft-app` (UI) | STUB, prints version only |

## Clean-room statement
HeatCraft is an independent implementation based only on public knowledge
(RF propagation theory, IEEE 802.11 standards, public vendor documentation).
It uses no code, assets, names or trademarks from any commercial product.
